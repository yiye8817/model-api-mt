# Hermes 知识学习平台设计

## 目标与使用场景

在现有工作台增加独立的「知识学习」Tab，让个人用户围绕自己的资料完成导入、阅读、提问、知识点探索和整合归档。Hermes 负责文档分类、结构分析、知识点提取、问答和综合整理；应用负责存储、检索、来源校验与交互展示。

进入 Tab 后可以看到目前已有的文档，查看每份文档对应的思维导图，浏览全部知识点和跨文档知识图谱，并选中文档提问。资料、分析成果、问答记录和归档在重启后仍可查看。

用户明确要求文件上传、链接导入、文档分类、结构分析、思维导图、知识点深度探索，以及对所有上传文档进行知识图谱整合归档。本文将「目前已有资料」解释为本平台资料及现有本地知识、内容库中已导入的文档；默认使用现有模型配置，面向个人本地使用。

## 实现方式

采用独立学习资料库与 Hermes 后台任务结合的方式。既有文档通过来源适配器接入，保留来源标识及修订；新增上传和网页正文存入学习资料库。所有图、知识点、引用和归档保存为结构化数据。

与直接嵌入 Hermes 聊天相比，此方式能够持久保存可交互的思维导图、提供完整知识点目录，并在文档更新或删除时更新跨文档关系。相比引入独立图数据库，SQLite 可以沿用当前部署方式，并通过文档、概念、关系及引用表支持首版所需查询。

## 页面与用户操作

### 独立入口

在中部 Tab 栏增加常驻「知识学习」入口。通过新建标签菜单也能定位到该 Tab，重复点击激活已有实例。沿用现有主题、Electron 与浏览器运行方式。切换到其他 Tab 后后台任务继续，返回时恢复选中文档及当前视图。

Tab 由资料侧栏和学习工作区组成。侧栏展示资料总数、分类、搜索、文件上传、链接导入和文档列表。每份文档显示标题、来源、分类和分析状态；分析状态包括待分析、分析中、已完成、需要更新和失败。工作区提供「文档学习」「全部知识点」「知识图谱」「整合归档」四个视图。

### 文档学习

选择文档后显示摘要、分类与标签，以及「原文」「思维导图」「文档问答」三个内容面板。原文优先使用保留的解析文本，并支持跳转来源片段。思维导图表达文档主题、章节、子主题和知识点的层级关系，节点支持展开、收起、缩放、定位和点击查看详情。

没有分析成果的文档显示「待分析」及「生成分析与思维导图」操作；失败显示原因及重试入口。不会生成用于占位的知识点或图节点。分析完成后导图与资料绑定，重新进入 Tab 可直接查看。

文档问答默认限定当前文档。用户可明确选择多份文档，或切换到全部资料提问；输入框上方持续显示范围。支持连续追问、停止生成及历史问答查看。回答中的引用可打开本 Tab 内的原文片段，并显示文件页码、行号或段落等已知位置；网页可打开保存的正文及原始链接。

### 全部知识点

以可搜索、可分页的列表展示所有有效分析成果中的知识点，支持按分类和来源文档筛选。知识点包含名称、说明、所属章节、关联文档、原文引用和相关知识点。点击条目可以定位到文档导图或知识图谱中的对应节点。

「深入探索」围绕选定知识点生成原理、前置知识、例子、常见误区、关联概念及后续问题。默认依据已选资料；超出资料的解释标为拓展说明，不能伪装成文档结论。探索记录绑定知识点和文档修订，能够再次查看或保存到归档。

### 知识图谱

默认展示整个学习资料库的有效文档、概念及关系，用户可按分类、文档和关键词筛选，也能从某个知识点展开邻接关系。文档节点与概念节点使用不同样式，关系显示关联类型，点击节点或边显示来源文档和引用。

图谱基于所有已完成分析的有效文档构建。顶部展示已覆盖与待分析文档数量，提供「分析待处理资料」及「更新图谱」入口。未分析资料仍出现在资料列表中，不能被误计为已进入知识图谱。

提供缩放、拖动和适配视图。数据量较大时分页获取节点和邻接子图，同时提供可搜索的关系列表，确保所有知识点和关系仍可访问。图形渲染优先使用项目内 React 与 SVG，实现确定性布局；界面不执行模型返回的脚本、HTML 或图表代码。

### 整合归档

按主题展示资料目录、来源文档、关键知识点、综合摘要与已有探索笔记。用户选择全部或部分文档后发起「生成整合归档」，由 Hermes 基于文档分析及相关原文生成有引用的主题笔记；资料之间存在差异时并列说明来源。

分类与标签支持手工修改，人工修改不被后续自动分析覆盖。归档绑定生成时的文档修订，资料更新后提示需要重新整理。支持下载 Markdown 笔记及包含节点、关系和引用的 JSON，导出内容与页面保存结果一致。

## 文档导入与既有资料接入

### 新增资料

支持多文件上传，首版格式为 TXT、Markdown、PDF 和 DOCX。单文件上限沿用现有文档解析约束 20 MiB，每次上传请求不超过应用现有 50 MiB 总限制。浏览器按批次上传，同批个别文件失败时有效文件继续处理。PDF 需要可提取文字；扫描件、加密文件及缺失解析依赖返回明确原因。

链接入口接受公开 HTTP 或 HTTPS 网页，复用已有公开地址校验、受控抓取和正文提取能力。保存原 URL、解析后的 URL、抓取时间与正文快照。读取登录页、脚本空页或失败响应时显示失败原因，用户可重试或改为上传文档。

上传后立即保存文档及任务记录，后台完成解析、切块、Hermes 分析和写入。文件名仅用于展示，实际副本按文档 ID 保存。内容摘要用于识别重复资料；相同内容可以复用分析成果，但保留各自来源信息。

### 既有资料

来源适配器读取 `local_knowledge` 中 `kind=document` 且未删除的来源，并读取 `knowledge` 内容库中按 `document:` 数据集保存的文档片段。页面初次打开和刷新时按来源 ID、修订及内容摘要进行幂等同步，不依赖本地向量服务或本地问答开关。

来源显示为「本地知识」「内容库」或「学习资料」。同源重复同步不增加文档；跨来源内容相同可以合并展示并保留多个来源入口。现有资料缺少学习分析时显示「待分析」，由用户点击单份或批量分析，避免浏览列表触发大批 Hermes 请求。

既有来源的读取通过小型查询接口封装，学习功能不直接在其他模块写入或修改数据。内容库仅保留分块时，使用已保存片段供阅读、分析和引用，不声称恢复原始页码或完整文件排版。页面注明位置来自已存片段。

历史会话、公开评测集及普通问答条目不自动作为文档导入。既有来源被删除、失效或更新时，在下次同步后移除其有效分析或标记需要更新；其他来源仍持有相同内容时保留该资料。

## 后端模块与 Hermes 集成

新增 `learning/` 包，职责划分如下。

| 模块 | 职责 |
| --- | --- |
| `store.py` 与 `schema.sql` | 文档修订、片段、分析、知识点、关系、问答、归档及任务的持久存储 |
| `sources.py` | 统一新增资料与既有资料的读取、同步和来源定位 |
| `ingest.py` | 文件与网页正文解析、切块、去重及修订生成 |
| `hermes.py` | Hermes 调用、任务事件转发、输出校验、超时及取消 |
| `analysis.py` | 分块分析、文档结构归并、知识点和关系抽取 |
| `retrieval.py` | 指定文档范围内的片段召回与引用校验 |
| `graph.py` | 跨文档概念归并、关系查询与来源管理 |
| `service.py` 与 `jobs.py` | 应用用例与持久化后台任务编排 |
| `api.py` | `/api/learning` 下的 Flask 接口及请求校验 |

在 `server.py` 注册独立 Blueprint，以回调注入既有资料读取能力和 Hermes 会话工厂，避免让学习模块导入整个服务器或依赖前端 WebSocket 连接。

Hermes 必须通过现有 Hermes 运行时与会话桥接执行，复用现有 provider 转发与模型配置。任务只保存 provider ID 和模型名称，不持久化密钥。未指定 provider 时使用既有默认配置；缺少 Hermes 或有效配置时列表与已有成果仍可查看，发起分析或提问返回可读错误。

后台任务独立于聊天 Tab，每个运行任务持有自己的 Hermes 会话与受控工作目录，完成、失败、取消后回收进程及临时运行时。复用现有工具进度事件展示当前阶段。分析使用结构化输出契约，服务端校验树结构、ID、关系端点和引用；一次修正仍不合格时任务失败，旧分析保留。

## 分析与问答流程

### 文档分析

1. 将解析出的正文切为带位置的片段，保存稳定片段 ID 与修订标识。
2. 按有限输入预算逐批交给 Hermes，提取结构、候选知识点和关系，每项必须附片段 ID 与原文引句。
3. 归并各批结果，生成分类、摘要、文档层级树和完整知识点目录。归并时以结构化提取结果为主，并保留回查原文的能力；不将长文静默截成开头一段。
4. 服务端校验引用确实存在于指定修订的片段中，关系端点存在，树无环且节点唯一；保存覆盖范围及实际完成片段数。
5. 在事务中激活完整分析版本、更新跨文档图谱并刷新归档状态。任何批次失败时保留未完成状态及原因，不发布覆盖不完整却标为完成的导图。

### 文档问答

1. 校验选中文档范围与有效修订；显式指定不存在或已删除文档时返回错误，不扩大成全部资料。
2. 在该范围内使用 SQLite FTS 与关键词召回片段；有可用的现有语义模型配置时可以追加语义召回，失败时返回可用的文本检索结果。长问答保留有限对话上下文与原始资料范围。
3. 将问题、上下文及编号证据交给 Hermes，要求区分资料结论与拓展说明。没有足够证据时直接说明资料无法回答。
4. 校验返回引用所属文档、修订和原文引句，保存回答与引用。无效引用不以有效来源呈现；需要文档证据却无法校验时给出失败原因并允许重试。
5. 页面显示回答、来源与提问范围，用户可继续追问、点击引用或将有用回答保存到归档。

知识点深入探索复用相同任务机制，但绑定知识点 ID 并保存结构化探索内容。分析文档、提问和探索均不依赖普通对话的本地模型精度评测门槛。

## 数据与一致性

学习数据保存到 `data/learning/learning.sqlite3`，文件副本与正文快照位于同一目录下。SQLite 使用 WAL 与外键约束，应用层不引入图数据库依赖。

| 对象 | 主要内容 |
| --- | --- |
| 文档及来源 | 文档 ID、标题、分类、标签、来源引用、内容摘要、当前修订、分析状态与人工修改字段 |
| 文档修订与片段 | 原文快照、片段顺序、正文、已知位置、内容摘要与所属修订 |
| 分析版本 | 所属文档修订、摘要、分类建议、结构树、模型信息、覆盖范围及完成时间 |
| 知识点与文档关联 | 概念名称、归一化名称、领域、说明、别名、所属文档章节与来源引用 |
| 关系与证据 | 关系端点、类型、所属分析版本和一条或多条有效证据 |
| 学习记录 | 提问范围、问题、回答、引用、追问上下文，以及知识点探索记录 |
| 归档 | 主题、文档修订集合、综合笔记、引用、更新时间与是否需要更新 |
| 任务 | 类型、文档范围、配置引用、状态、阶段、完成计数、错误与取消标记 |

知识点归并以归一化名称、领域及可核对的别名为依据，避免把不同领域的同名概念直接混合。同一概念可以关联多份文档，保留各文档的定义和证据。首版图谱通过各文档的概念及关系增量归并，不逐对比较所有文档。

每条分析、关系、问答引用和归档记录均绑定具体修订。文档更新后旧成果保留供查看并标记过期，默认图谱与新问答使用当前有效版本。删除某来源或文档时，只移除其支持的关系与关联；仍有其他有效证据支持的概念或关系继续保留。

学习模块自有资料的删除清理本模块文件副本及派生成果。既有资料的移除仅取消本 Tab 的收录，并保存排除标记避免刷新后重新出现；原来源由其所属模块管理。

## 接口契约

所有查询在没有 Hermes 和向量模型的情况下仍可读取已存资料与成果。列表接口提供分页参数，返回总数和当前页。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/learning/status` | 后端能力、文档数、已分析数、待更新数、知识点数与运行任务 |
| `POST /api/learning/sync` | 幂等同步既有文档来源，返回新增、更新及失效数量 |
| `GET /api/learning/documents` | 按标题、分类、来源和状态筛选资料 |
| `POST /api/learning/documents/upload` | multipart 上传多文件，返回各文件的文档 ID、任务 ID 或错误 |
| `POST /api/learning/documents/link` | 提交网页 URL，返回文档 ID 与后台任务 ID |
| `GET /api/learning/documents/<id>` | 文档元数据、分析状态、最新成果标识与来源 |
| `PATCH /api/learning/documents/<id>` | 更新标题、分类及标签，标记人工修改 |
| `DELETE /api/learning/documents/<id>` | 删除自有资料或取消既有资料收录 |
| `GET /api/learning/documents/<id>/content` | 按片段读取正文，支持引用定位 |
| `GET /api/learning/documents/<id>/analysis` | 文档摘要、章节树、思维导图节点、知识点和引用 |
| `POST /api/learning/analyze` | 分析显式文档集合或全部待分析文档，返回任务 ID |
| `GET /api/learning/concepts` | 查询全部有效知识点及来源文档，支持筛选与分页 |
| `GET /api/learning/concepts/<id>` | 知识点详情、关联文档、引用与探索记录 |
| `POST /api/learning/concepts/<id>/explore` | 发起知识点深度探索任务 |
| `GET /api/learning/graph` | 按范围、关键词和邻接节点读取图谱，返回覆盖数量与分页信息 |
| `GET /api/learning/conversations` | 查询文档问答历史，支持按文档过滤 |
| `GET /api/learning/conversations/<id>` | 读取问题、回答、引用和提问范围 |
| `POST /api/learning/questions` | 提交问题、明确文档范围及可选追问会话，返回任务 ID |
| `GET /api/learning/archives` | 读取主题归档及更新状态 |
| `POST /api/learning/archives` | 基于文档集合生成整合归档任务 |
| `GET /api/learning/archives/<id>` | 读取综合笔记、文档目录、知识点和引用 |
| `GET /api/learning/archives/<id>/export` | 下载指定归档的 Markdown 或 JSON |
| `GET /api/learning/jobs/<id>` | 查询任务状态、阶段、进度、结果及错误 |
| `POST /api/learning/jobs/<id>/cancel` | 请求取消后台任务和对应 Hermes 进程 |

创建后台任务返回 202；参数无效返回 400；对象不存在返回 404；已有同范围同修订任务正在运行时返回其任务 ID，避免重复执行。运行时缺少 Hermes 或 provider 不可用返回明确的能力错误。任务内部错误保存到任务记录，查询任务本身仍返回正常响应。

## 任务生命周期与错误处理

任务状态为 queued、running、completed、failed 或 cancelled。导入及分析阶段为读取或抓取、解析、切块、分块分析、整合、保存；问答阶段为检索、Hermes 回答和保存。页面使用轮询读取状态与结果，切换 Tab 不取消任务，停止按钮显式取消。

初始后台并发为两个任务，同一文档修订同时只运行一份分析。取消会中止对应 Hermes 调用，worker 在阶段边界和提交前检查取消状态，迟到回调不能发布成果。任务失败保留已上传正文及最后一份有效分析，允许重试。

服务启动时将原 queued 任务恢复入队，将中断的 running 任务标记为失败并说明服务中断；避免在用户未知的情况下重复调用模型。所有完整成果与历史记录保持可读。

进度以实际完成片段数、阶段和覆盖文档数表达。模型推理等待时间不伪装成精确百分比。解析异常、网页无法读取、模型超时、输出结构不合格及引用校验失败分别提供可理解的错误消息。

## 前端模块

新增 `src/components/learning/`，包含总面板、资料列表、导入表单、文档学习视图、思维导图、知识点目录、图谱、问答区及归档视图。共享类型与 API 调用放入 `src/lib/learningTypes.ts` 和 `src/lib/learningApi.ts`，任务轮询单独封装为 Hook。

`App.tsx` 只负责增加 Tab 类型、固定入口、菜单定位以及内容挂载。图、列表与引用使用同一组文档和概念 ID，确保页面之间的跳转一致。引用点击打开本 Tab 的片段面板，外部网页复用现有打开网页能力。

## 验收与验证

1. 打开「知识学习」Tab，能够看到既有两处文档与新增资料；刷新和重启后资料及分析结果仍存在，重复同步不增加重复文档。
2. 上传文本、Markdown、可提取文字的 PDF、DOCX 和导入公开网页，均可获得实际解析内容；不支持的文件及无法读取的网页显示原因。
3. 文档分析完成后显示对应结构树、可交互思维导图、知识点与可点击原文引用；长文后半部分的知识点能够进入结果，覆盖计数准确。
4. 全部知识点视图能够搜索和筛选所有已分析资料的概念，点击后可定位文档及导图节点，深度探索记录可保存和再次查看。
5. 知识图谱覆盖所有有效分析文档，共有概念显示多份来源；删除某份资料后，有其他来源支持的节点及关系继续存在。
6. 对单文档、多文档及全部资料提问时，回答引用全部属于用户选定范围且能定位原文；资料没有答案时说明不足，追问保留范围。
7. 整合归档包含选定文档目录、关键知识点、综合笔记及引用，导出内容与保存结果一致，文档更新后显示过期状态。
8. 分析失败、任务取消及服务重启均不覆盖已有有效成果；关闭或切换 Tab 不丢失后台任务。

Python 测试覆盖资料同步、解析、修订、结构与引用校验、问答范围、概念归并、来源删除、任务取消和重启处理。Flask API 测试覆盖上传、链接、任务查询及成果读取。React 测试覆盖 Tab 入口、资料选择、导图节点交互、知识点筛选、问答引用及失败状态。运行相关回归、TypeScript 检查及生产构建；可用时以实际 Hermes 验证文档分析、问答和整合归档。使用替身运行的测试不能作为真实 Hermes 已连通的结论。
