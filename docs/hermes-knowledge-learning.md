# Hermes 知识学习平台

工作台顶部的「知识学习」Tab 将资料阅读、文档思维导图、知识点探索、知识图谱和整合归档放在同一工作区。页面与分析结果保存在本机，后台生成使用现有 Hermes 运行时及应用默认模型配置。

## 导入与查看资料

左侧资料库可以上传 TXT、Markdown、可提取文字的 PDF、DOCX，单文件最多 20 MiB；多文件分批上传，个别文件失败会单独显示原因。PDF 和 DOCX 使用项目已声明的可选解析依赖：

```bash
.venv/bin/python -m pip install -r requirements-knowledge.txt
```

网页链接导入只读取公开 HTTP 或 HTTPS 正文，保存原始链接、最终链接、抓取时间和正文快照。登录页或没有可读取正文的页面会报告失败。网页正文抓取最多 512000 bytes，达到上限时资料中显示快照范围。

首次进入 Tab 和点击刷新会同步「本地知识」及「内容库」已导入的文档。既有资料先显示为待分析；点击单份文档的「生成分析与思维导图」或图谱中的「分析待处理资料」生成学习成果。历史会话、公开评测集及普通问答记录不会自动混入文档库。

新上传与链接资料自动进入解析和分析任务。Hermes 暂不可用时，已经解析的正文仍保留，可配置模型后重试。资料阅读不需要本地向量服务，也不依赖普通对话的本地精度评测。

解析或网页抓取失败后，重试会重新读取保存的文件副本或原始链接；已经解析成功的资料只需重试分析。排队或运行中的任务取消后都可以重新发起。

## 文档学习与提问

选择文档后，可以切换「思维导图」「原文」「文档问答」。思维导图支持展开和收起节点、拖动、缩放及适配视图；点击知识点节点查看原文引用。原文按片段分页，保留解析器已有的行、PDF 页码或 DOCX 段落与表格位置；内容库历史片段使用片段编号。

文档问答默认限定当前文档，也可选择左侧勾选的多份资料或全部资料。每轮回答保存原文引用，点击引用会打开对应修订的原文片段。资料不足时会说明无法回答，超出资料的教学解释显示在「拓展说明」中。

连续追问保留原资料范围和修订。若文档已更新，请新建问答；历史记录仍可查看。问答中的「保存为学习笔记」直接保存已有回答和引用，不会再次调用模型。

## 知识点与知识图谱

「全部知识点」支持名称、说明、别名搜索，以及分类、当前文档和已勾选资料筛选。知识点详情显示各文档来源，能够跳转到来源文档及导图。点击「深入探索」生成原理、前置知识、实例、误区、关联概念和后续问题，并保存探索记录。

选择当前文档或已勾选资料后，深入探索严格使用该范围的知识点定义和原文证据。

「知识图谱」汇总当前有效文档分析中的文档节点、概念和关系，展示已分析资料覆盖数。点击概念可以展开邻接关系，点击关系查看证据；关系列表与分页可以访问全部保存关系。不同领域的同名概念分别保存，同领域共有概念保留多份文档的定义和引用。

更新资料后，旧分析仍保留，但默认知识图谱使用当前有效分析。移除一份资料只移除其支持的关联，仍有其他资料支持的概念和关系继续显示。

原资料库将来源标记为失效后，同步会将其退出当前检索和图谱，旧导图保留为历史结果并提示更新。原来源重新导入后可继续同步；在学习平台主动移除的来源会继续排除。

## 整合归档

「整合归档」可以按主题整合全部或所选资料，生成综合笔记及来源目录。先完成文档分析，再生成整合归档。已经保存的文档问答和知识点探索也可以存为学习笔记。

归档保留生成时的文档修订。资料更新或移除后显示需要重新整理，已经保存的笔记不被覆盖。Markdown 导出包含笔记与原文引用；JSON 导出保留生成时的概念、图谱、关系及证据。

## 模型配置与任务

Hermes CLI 必须已安装并可运行。默认使用应用默认 provider 及其选中模型；未选应用 provider 时使用 Hermes 自身配置。provider 凭据通过现有本地代理复用，学习任务只保存配置 ID 和模型名称。学习分析会话禁用 Agent 工具，文档正文作为待学习数据处理。

后台最多同时执行两个任务。同一文档修订的分析请求复用正在运行的任务，批量操作按文档排队。页面显示实际阶段与完成片段数，停止按钮取消对应任务；切换应用 Tab 只停止页面观察，后台任务继续。

服务重启会恢复尚未开始的 queued 任务，将中断的 running 任务标记为失败并提供重试。失败或取消不会覆盖上一份有效分析。

## 数据与验证

学习数据位于 `data/learning/`，包括 `learning.sqlite3`、上传副本和正文修订。备份时停止服务并复制整个目录。移除新上传资料会清理学习模块副本；移除既有来源仅取消本 Tab 收录，原来源继续由本地知识或内容库管理。

自动化测试使用临时目录及 Hermes 会话替身，覆盖实际解析、SQLite、后台任务和 HTTP 完整流程。运行：

```bash
PYTHONPATH=desktop-agent/src .venv/bin/python -m pytest
npm run test:knowledge
npx tsc --noEmit
npm run build
npm run test:web-chat
```

真实 Hermes 的连通性与当前模型配置相关，单独以小型测试文档验证分析、问答、探索和归档；替身测试不代表远程模型已连通。
